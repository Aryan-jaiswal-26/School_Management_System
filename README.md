# 🎓 School Management ERP

A comprehensive and enterprise-grade School Management ERP built using the MERN Stack (MongoDB, Express.js, React.js, and Node.js). This platform streamlines academic, administrative, financial, and communication workflows for educational institutions through a centralized digital ecosystem.

## 📦 Installation

### Clone Repository

```bash
git clone https://github.com/tanmaypatil0001/school-management-erp.git
cd school-management-erp
```

### Install Dependencies

Backend

```bash
cd backend
npm install
```

Frontend

```bash
cd client
npm install
```

### Environment Variables

Create `.env` file in server directory:

```env
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
PORT=5000
```

### Run Application

Backend

```bash
npm start
```

Frontend

```bash
npm run dev
```
